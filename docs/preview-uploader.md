# PreviewUploader

Drag & drop file uploader with image previews, PDF detection and reject reasons.

## Usage

```tsx
<PreviewUploader maxSizeMb={5} onFilesSelected={(files) => upload(files)} />
```

## Install

```bash
npx shadcn@latest add "https://raw.githubusercontent.com/thirdbase1/gaps-ui/main/public/r/preview-uploader.json"
```
